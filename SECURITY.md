# Security policy

## Supported version

Security fixes are maintained for the latest `1.x` release of this portfolio project.

## Reporting a vulnerability

Do not open a public issue containing exploitable details, credentials or personal information. Use GitHub's private vulnerability reporting feature when enabled, or contact the repository owner privately through the profile contact method.

Include:

- affected component and version;
- reproducible impact without real customer data;
- suggested remediation when available.

## Demo credentials

`admin@pulseflow.local` and `PulseFlow123!` are intentionally public local fixtures. They must never be reused in a public deployment.

## Scope note

PulseFlow is an educational portfolio system. It does not store card data and is not a compliance certification. See [`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md) for threats, controls and the production checklist.
